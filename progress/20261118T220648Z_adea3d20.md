# 2026-11-18 UTC — feature session adea3d20 (via /work), issue #39

- **Solver: CDCL** (`core/src/lib.rs`), in front of the verified DPLL `solve`, which stays as the
  fallback. Iterative trail with decision levels and reasons, two watched literals (watch lists as
  linked lists in flat `Vec<usize>`s: `head`, `next`, `wpos`), first-UIP conflict analysis with
  backjumping, VSIDS-like integer activities (bump/rescale), phase saving, restarts every 100·1.5^k
  conflicts. No clause deletion.
- **Design for verification: an untrusted search with checked answers.** The search functions only
  need to return without a panic: every index is checked before use (`if v < x.len()`), every loop is
  a fuel-bounded `while` (running out of fuel just stops it), so no invariant of the search state is
  needed. The answers are checked:
  - `Sat`: `model` copies the assignment into `vec![false; n]` and `satisfies` checks it against the
    formula (post: `formula_sat`).
  - learned clauses: `certify` checks, before a clause is learned, that it follows from the formula
    and the clauses learned before: from the negation of the learned clause, the reasons along the
    trail (`force_trail`, `reason_ok`) force the values of the current assignment until the
    conflict clause is false. Its contract: every assignment that satisfies the clause database
    satisfies the learned clause (`certify_sound`, `forced_sound_step`). The main loop keeps
    `learned_ok f L` (every learned clause holds under every model of `f`).
  - `Unsat`: a certified empty clause at decision level 0.
  - When a check fails or the search runs out of fuel, `cdcl` returns `None` and `solver` runs `solve`.
  No length relation between lists is assumed anywhere in the soundness argument (HOL lists may be
  longer than `2^64`, so `len(x) == n` gives no `length x = unat n`).
- **Proofs**: new theory `proof/Sat_CDCL.thy` (session `Sat_Proof`), ~1450 lines: contracts of all
  29 new functions (no panic for the search; the semantics above for the checks), `cdcl_spec`
  (`cdcl_post`). `Sat_Top.solver_spec` combines `cdcl_spec` with `solve_spec`; `solver_correct`
  unchanged. `spec/`: only the locale `Sat_heap` (new mutable-local types `Search`, `Clause list`,

  disabled), each worked around in the code:

     `&mut Vec<Lit>`), one of the two points-to facts is lost (`points_to_localizes … ?g ?v` left
     open): no function takes two `&mut` arguments any more (the learned literals are a field of
     `Search`, copied out by `copy_learnt`);

     its own function `on_conflict`;
  4. a `loop` without `break` that runs out of fuel ends in `panic!("unreachable …")` in the
     translation (unlike `while`): the main loop is `while steps < usize::MAX`.

    HTTP 500), but `isabelle_multi_attempt` never got a scratch session, and editing the file while
    the server was still checking it produced spurious "Cannot join unrelated theory certificates"

    (`word64_less_of_nat`, `word64_less_max`, `big_c`, …) closes almost all no-panic goals; plain
    `auto` hangs on goals with large record-update premises.
