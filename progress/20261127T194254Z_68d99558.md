## What was slow, and the fix

Per-goal trace (method `trace_all`, see #139's entry) of every `apply (all …)`: `sok_tac` closed
every goal it was given, but at 0.5–5 s each, on ~110 goals of these shapes:
- `sok_in B.0`/`sok B.7` closed by a premise (≈1–2 s each in `sok_tac`);
- `sok` of a state that differs from a premise's only by updates of fields outside `sok`
  (`seen`, `inc`, `nres`, `fail`, …), by element updates (`xs[i := v]`, `take`, `[]`) of
  `stack`/`toclear`/`hint`/`learnt`, and by pushes onto `stack`/`toclear`/`hint`;
- `∃y. rvec_append_val (Search_hint s) [x] = Some y` (4.7 s).
`search_bound?` also failed on each of these `sok` goals (≈ 0.1–0.2 s each, ≈ 15 s in total).

New in `Sat_Minimize.thy` (no other theory, no contract, no lemma statement used elsewhere
changed): rules `sok_frame` (19 non-`sok` fields), `sok_elems`, `sok_push` (any push of ≤ 8
elements; the pushed vector is a variable with an equation `Search_X s = v`, so a push on top
of other updates still matches), and the method `sok_fast`: it matches `sok_in`/`sok`/push goals
only, peels the updates with these rules, and closes the rest with `sok_asm`, `simp (no_asm)`
(equations, lengths) and `simp add: not_le` (bounds). Every cascade now runs
`(sok_fast; fail)?` first, then `search_bound?`, then `(sok_tac; fail)?` (kept as a fallback for the
few goals left). In `Search_compact_spec` the `FalseE, swap_ok2` step runs before `sok_tac`,
which failed on that goal for 3.4 s.

## How

- Task sessions in an untracked directory with renamed sessions (`Sat_t145`, `SatSpec_t145`,
  `SatSearch_t145` = `Sat_Partial`…`Sat_Search`, `SatMin_t145` = `Sat_Minimize` alone,
  `SatProof_t145` = the whole `Sat_Proof`), with the qualified imports rewritten by `sed`.
  A `Sat_Minimize`-only pass took ~2 min.
- Command timings: `Store.read_command_timings` + `Properties.uncompress` from
  `isabelle scala` (stdin script), symbol offsets mapped to lines in Python.
- Isar has no `*` combinator: write `(m+)?`. A `match … ⇒ succeed` must be parenthesised
  before a following `,`.
